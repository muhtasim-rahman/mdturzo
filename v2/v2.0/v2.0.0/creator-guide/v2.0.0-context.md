## Architecture Decisions (v2.0.0)

- **Feed system:** `blogs` + `posts` একটাই `feed` table এ type column দিয়ে — `type: 'blog' | 'post'`
- **Comment limit:** Per user max 10/day (across all content), 3/hour per content
- **Admin verify:** Firebase RTDB `/admins/{uid}: true` + Supabase `admins` table — double check
- **Image hosting:** ImgBB via Cloudflare Worker (Firebase Storage use হচ্ছে না)
- **Auth:** Firebase Auth only — Supabase Auth disabled. `users.id = Firebase UID`
- **Notifications:** Firebase RTDB primary (realtime), Supabase `notifications` table backup/history only

## Pending Manual Setup Steps

### 1. Cloudflare Worker Deploy
- Dashboard → Workers & Pages → Create Worker
- Paste `cloudflare-worker.js` content
- Settings → Variables → Add all secret variables above

### 2. Firebase RTDB Rules
- Firebase Console → Realtime Database → Rules
- Paste content of `firebase-rtdb-rules.json` → Publish

### 3. Supabase SQL
- Supabase Dashboard → SQL Editor → New Query
- Paste `supabase-schema-v2.0.0.sql` → Run

### 4. First Admin Setup (After v2.7.0 auth works)
- Login with your account → get your Firebase UID
- Firebase Console → RTDB → Data → `/admins/{your-uid}` → set to `true`
- Supabase → Table Editor → `admins` → insert `{id: your-uid, email: mdturzo.dev@gmail.com}`

### 5. Firebase Auth Action URL
- Firebase Console → Authentication → Templates → each template
- Action URL: `https://mdturzo.web.app/auth/action`

### 6. Firebase Analytics
- Auto-enabled via `measurementId: G-SHM2013GKK`
