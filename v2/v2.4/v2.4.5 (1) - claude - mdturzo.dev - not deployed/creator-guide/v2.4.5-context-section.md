## v2.4.5 — Restructure, DevBanner, Project Count Fix
**Date:** 2026-06-04 | **Status:** ✅ Deployed | **Build:** Clean (0 errors)

### What Changed

#### 1. DevBanner — Redesigned & Repositioned
- **File:** `src/components/layout/DevBanner.jsx` (moved from `ui/` → `layout/`)
- **Design:** Minimal thin strip — neutral surface bg, subtle border-bottom. No amber/danger. Uses `--bg-surface`, `--text-secondary`, `--accent-primary` variables. Has: small code icon, "Site under active development" text, `37% complete` pill (hidden on mobile), shimmer progress bar, dismiss button.
- **Position fix:** DevBanner now properly appears **above** the navbar on ALL pages including Home/About.
  - `Layout.jsx` wraps `<DevBanner>` + `<Navbar>` in a single `<div class="relative">`.
  - `Navbar.jsx` home/about case changed from `absolute top-0 left-0 right-0` → `absolute left-0 right-0` (no `top-0`), so navbar's static position defaults to after the DevBanner.
- **CSS:** `dev-banner-*` classes added to `index.css`.
- Old `src/components/ui/DevBanner.jsx` — **DELETED** (moved).

#### 2. Component Folder Restructure
`components/` now follows a strict per-page folder pattern:

| Folder | Contains |

#### 3. Project-Specific CSS Extracted

- Contains: `.rp-grid`, `.proj-page-grid`, `.proj-card`, `.prose-content` (all variants), `.breadcrumb-nav`, `.share-panel`, `.comment-card`, `.scrollbar-none`, `.proj-detail-sidebar`
- **Removed from `index.css`**: Lines 773–930 (project page & detail styles)
- `index.css` now only has global/shared CSS
- Imported in: `ProjectsPage.jsx`, `ProjectDetailPage.jsx`, `RecentProjects.jsx`

#### 4. Project Count — Now Live from DB
- **Problem:** All stats showing project count were reading from `site_settings.statsProjects` (manually set to `16`).
- **Fix:** New `getProjectCount()` in `supabase.js` — counts `projects` rows where `status='published' AND visibility='public'`.
- `useSiteSettings.js` now runs `Promise.all([getSiteSettings(), getProjectCount()])` — adds `projectCount` to the settings object.
- `site.config.js` defaults: `statsProjects` removed → `projectCount: 0` (fallback).
- **Updated components:**
  - `Hero.jsx` → `settings?.projectCount ?? 0`
  - `AboutMini.jsx` → `settings?.projectCount ?? 0` (was hardcoded `16+`)
  - `AboutStory.jsx` → `s?.projectCount` (was `s?.statsProjects ?? '16+'`)
  - `Skills.jsx` → `settings?.projectCount ?? 0`
  - `Stats.jsx` → `settings?.projectCount ?? 0`

#### 5. RecentProjects — Static Fallback Removed
- **File:** `src/components/home/RecentProjects.jsx` — **fully rewritten**
- Removed: `STATIC_FALLBACK` array of hardcoded demo project data
- Now: if no data from Supabase → shows `EmptyPlaceholder` (FolderOpen icon, "No projects yet", "Retry" button)
- Skeleton grid counts match responsive visible count (6/4/3)
- On fetch error: shows empty placeholder with retry key increment

### Supabase Note
`getProjectCount()` queries: `projects` table, filter `status=published AND visibility=public`, `count: 'exact', head: true`. If your projects table uses different column names for status/visibility, update the `.eq()` filters in `supabase.js`.
