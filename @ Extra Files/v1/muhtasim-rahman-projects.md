### 2. QR Prism - Advanced QR Code Generator

**Project Name:** QR Prism  
**Short Name:** QR Prism  
**GitHub URL:** https://github.com/muhtasim-rahman/qr-prism  
**Preview URL:** https://muhtasim-rahman.github.io/qr-prism  
**PDF Preview URL:** N/A  
**Version:** v3.4

**Short Description:**  
A feature-rich Progressive Web App for generating, scanning, and managing QR codes with batch processing and cloud storage.

**Detailed Description:**  
QR Prism is a comprehensive QR code solution built as a Progressive Web Application with extensive functionality covering generation, scanning, batch processing, and cloud management. The application features multiple input methods including CSV/TXT/JSON drag-and-drop batch generation with JSZip export capabilities, a sophisticated scanner with CSS overlay and type-based action buttons, profile editing with ImgBB image upload integration, and a messenger-style report system for user feedback. The app implements a three-tier Service Worker caching strategy for optimal offline performance, secure admin panel access via SHA-256 hashing with Firebase Database role verification, and Firebase-backed user authentication and data storage. The architecture evolved through major versions from Canvas rendering (v2.7) to SVG-based rendering (v3.4) with modular CSS organization. The admin system was redesigned with server-side enforcement using Firebase DB structure `admins/{uid}: true` for enhanced security.
