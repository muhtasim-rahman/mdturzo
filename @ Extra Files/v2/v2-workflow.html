① System Architecture — কোন Service কী করে
পুরো website এর সব services এবং তাদের দায়িত্ব।

⬡ React + Vite (Frontend)

  • Website এর সব UI render করে
  • React Router → clean URLs
  • Zustand → global state
  • Framer Motion → animations
  • Tailwind CSS → styling
  • Firebase Hosting এ deploy হয়

⬡ Firebase (Auth + Realtime)

  • Auth → login, signup, OAuth
  • Realtime DB → notifications live
  • Realtime DB → online presence
  • Hosting → website deploy
  • Analytics → GA4 tracking
  • Password reset email পাঠায়

⬡ Supabase (Main Database)

  • Projects, Blogs, Posts data
  • Users, Comments, Likes, Reports
  • Reviews, Messages, Badges
  • Site settings (dynamic data)
  • Activity logs, Analytics
  • Row Level Security → data protect

⬡ Cloudflare Worker (Proxy)

  • Secret API keys secure রাখে
  • /upload-image → ImgBB proxy
  • /verify-recaptcha → spam check
  • /send-email → Resend proxy
  • CORS protection
  • Rate limiting check

⬡ External APIs

  • ImgBB → image hosting
  • Resend → email delivery
  • reCAPTCHA v3 → bot score
  • ipapi.co → IP geolocation
  • Hotjar → heatmaps
  • Sentry → error tracking

⬡ TipTap (Rich Editor)

  • Blog + Project content editor
  • Templates (Standard, Showcase...)
  • Image insert → ImgBB upload
  • Code blocks, tables, embeds
  • Auto-save as draft
  • Preview mode

③ Authentication Flow — Login/Signup
User কীভাবে account তৈরি করে, login করে, এবং admin হিসেবে verify হয়।
Signup Flow
1

Form Fill

Name, @username, email, password, checkbox + reCAPTCHA v3 background এ check

2

Spam Check

Cloudflare Worker → reCAPTCHA score verify। Score < 0.5 → block। Honeypot check।

3

Firebase Auth Create

Email/password account তৈরি হয়। Firebase UID generate হয়। Verification email পাঠানো হয়।

4

Supabase User Create

Firebase UID দিয়ে Supabase users table এ entry। usernames table এ @username।

5

Profile Page Redirect

Profile complete করার জন্য redirect। Resend → admin এ new user notification।

Admin Verification Flow (Background)
1

Firebase Token Check

Login করলে Firebase JWT token auto check। Invalid হলে logout।

2

Supabase Admin Check

admins table এ email match আছে কিনা। না থাকলে regular user।

3

/admin Access

Admin confirmed → panel access। Not admin → 404 page (existence reveal হয় না)।

4

Sensitive Action

User delete, settings change → confirmation modal। Normal browse তে কোনো interruption নেই।

④ Image Upload Flow — Compress → Upload → Store
User বা Admin ছবি upload করলে কী হয়। API key কখনো browser এ আসে না।
1

Image Select

User image file choose করে। Original size + dimensions দেখানো হয়।

2

Crop (Cropper.js)

Aspect ratio fix করে crop। Profile: 1:1 | Banner: 16:9 | Thumbnail: 16:9 | Review: free।

3

Compression Options

Normal user: auto 150KB max, WebP, no options।
Admin: Preset (None/Low/Medium/High/Custom), Quality slider, Max size, Format select। Estimated output preview দেখায়।

4

Compress Preview

Left: Original | Right: Compressed। Size comparison। Buttons: Accept / Re-compress / Cancel।

5

Cloudflare Worker → ImgBB

React → POST /upload-image → Worker adds ImgBB API key → ImgBB upload → URL return। Key কখনো browser এ আসে না।

6

Supabase Save

ImgBB URL → Supabase তে store। naming: pt_{slug}_{ts}.webp, up_{uid}_{ts}.webp etc।

⑫ Version Development Workflow
AI দিয়ে প্রতিটা version কীভাবে develop করবে — step by step।
1

নতুন Chat খোলো

Claude.ai তে নতুন conversation। Master Prompt পুরোটা copy-paste করো।

2

Version বলো + Files দাও

"v2.X.0 এর কাজ করব" বলো। Per-version guide অনুযায়ী extra files attach করো।

3

AI Code Generate করে

AI সব code লিখবে। তুমি শুধু wait করো। ZIP + SQL script + commit message পাবে।

4

Local Test করো

ZIP extract → .env বানাও → npm install → npm run dev → localhost:5173 এ test।

5

Bug পেলে — Same Chat এ বলো

Same chat এ error message দেখাও। AI fix করবে। Version হবে v2.X.1, v2.X.2 etc। New ZIP পাবে।

6

Deploy করো

npm run build → firebase deploy → mdturzo.web.app এ live।

7

পরের Version

নতুন chat → Master Prompt → "v2.(X+1).0 এর কাজ করব" → আগের ZIP দাও।
